## Context

The USD-M 1d backfill (`Usdm1dBackfillOrchestrator` + `BinanceUsdM1dBackfillExchange` + `SqlitePerSeriesCandleStore`) landed under `trading-platform-marketdata-binance-1d-backfill`. Storage identity today is: the Binance `symbol` string flows straight through `SeriesDescriptor.Symbol` into `SeriesTableNaming.ToPhysicalTableName`, which currently requires `^[A-Za-z0-9]+$`. SQLite receives the rendered name inside a double-quoted identifier (`"<Symbol>_<TF>"`).

Live USD-M `exchangeInfo` today (537 TRADING PERPETUAL USDT contracts) includes three symbols with CJK characters (`龙虾USDT`, `币安人生USDT`, `我踏马来了USDT`) and 17 with leading ASCII digits (`1INCHUSDT`, `1000PEPEUSDT`, `4USDT`, `0GUSDT`, …). `OrderBy(Ordinal)` puts the CJK names last, so the orchestrator processes ~534 symbols and then throws `ArgumentException: "Symbol must be alphanumeric."` with no per-symbol recovery, aborting the whole run.

The deeper identity problem (single string carrying venue + contract type + base + quote + display name, storage named by that string) is scoped to a follow-up change, `marketdata-instrument-identity-and-candles-registry`. This change is the minimal surgical fix to land first: tighten where the rule lives, make the loop resilient, and leave everything else alone.

## Goals / Non-Goals

**Goals:**

- Accept every symbol Binance returns for the existing universe filter (including Unicode and digit-prefixed names) without changing the filter, the Binance.Net wiring, or the storage topology.
- Move the character-safety rule from "what characters a `SeriesDescriptor.Symbol` may contain" (too strict) to "what characters the storage layer refuses to render into an identifier" (the actual invariant).
- Make the orchestrator loop survive any single-symbol failure, so one unexpected surprise (Unicode, HTTP 4xx, disk blip) never aborts the remainder of the run.
- Make post-run diagnosis possible: failures are visible on the checkpoint without touching a log file.
- Ship this without a checkpoint schema-version bump (v1 files written by the existing build must keep loading).

**Non-Goals:**

- Introducing `InstrumentId`, `venue`, `contract_type`, or any registry.
- Changing `SeriesDescriptor` shape, `ICandleSeriesWriter`/`ICandleSeriesReader`, `IUsdM1dBackfillExchange`, or the CLI surface.
- Moving off per-series tables or changing SQL-quoted identifiers.
- Modifying the universe filter (`TRADING` ∧ `PERPETUAL` ∧ `USDT`) or paging/ordering semantics.
- Retrying failed symbols inside a run. Failed symbols are retried only on the next run (same behavior as today for any non-complete symbol).

## Decisions


| Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Rationale                                                                                                                                                                                                                                                                                 | Alternatives considered                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Safety predicate at storage boundary, not at domain validation.** `SeriesTableNaming.ToPhysicalTableName` keeps doing the check, but the predicate becomes: non-empty, contains no ASCII control character (`U+0000`–`U+001F`, `U+007F`), and contains no `"`. The existing upper-casing of `Symbol` and the timeframe check (`[A-Za-z0-9_-]`, `-` → `_`) are unchanged.                                                                                                                                                                                                                                             | The actual SQL risk in a double-quoted identifier is an unescaped `"` or a control character; Unicode letters and digits are valid identifier content in SQLite quoted identifiers. A domain-level alphabet rule was over-broad and forced legitimate exchange strings out of the system. | (a) Keep alphanumeric and sanitize upstream — pushes the problem into the adapter and silently renames symbols on disk. (b) Use the identity/registry approach in this change — too big, scoped to the follow-up. (c) Remove the predicate entirely — leaves control chars / `"` as a latent SQL-injection / breakage hazard even though Binance doesn't emit them today. |
| **Upper-casing stays the same.** `Symbol.ToUpperInvariant()` still runs before rendering. For ASCII symbols this is a no-op visually (Binance already upper-cases). For Unicode we rely on `ToUpperInvariant`, which is identity for code points with no ASCII-culture uppercase mapping (CJK characters are unchanged).                                                                                                                                                                                                                                                                                               | Keeps the contract identical for all existing symbols; Unicode names stay readable.                                                                                                                                                                                                       | Lower-casing or leaving mixed case: diverges from the existing convention and the existing test (`BTCUSDT_1D`).                                                                                                                                                                                                                                                           |
| **Per-symbol failure isolation with `try/catch` at symbol scope in `Usdm1dBackfillOrchestrator.RunAsync`.** Every line from series-descriptor construction through `EnsureDailySeries`, `SeriesTableNaming.ToPhysicalTableName`, checkpoint updates, exchange calls, and writer calls for one symbol is wrapped in a single `try`. On exception we log `LogWarning` with the symbol and exception message, record the failure on the checkpoint entry, save the checkpoint, and `continue`. `OperationCanceledException` is not swallowed — it continues to propagate (cancellation cannot be masked by a bad symbol). | Simplest shape that meets the spec "healthy symbols still complete" scenario. Matches existing log verbosity.                                                                                                                                                                             | (a) Fine-grained try/catch per internal step — more code, same observable behavior. (b) Fail fast on any error — the current bug. (c) Retry in-run with backoff — scope creep; rate-limit/backoff is already delegated to Binance.Net per the parent spec.                                                                                                                |
| **Additive checkpoint fields, no schema bump.** `BackfillCheckpointSymbolEntryV1` gains two optional fields — `LastErrorMessage : string?` and `LastErrorAtUtc : DateTimeOffset?` — with `JsonIgnoreCondition.WhenWritingNull`. `schemaVersion` stays `1`. Successful runs clear both fields (set to `null`) when the symbol next completes.                                                                                                                                                                                                                                                                           | The archived design pinned `schemaVersion = 1` with "Optional later: …" language — additive nullable fields are explicitly the extension path. Old checkpoint files produced by the current build load unchanged; the orchestrator just populates the new fields.                         | Bumping to `v2` only to add two nullables would trip the path-mismatch reset path in `Usdm1dBackfillOrchestrator.RunAsync` and force operators to rebackfill.                                                                                                                                                                                                             |
| **A failure does not mark `Complete = true`.** The existing "no more rows" / "partial last page" paths still set `Complete = true`; the catch path only records the error on the entry.                                                                                                                                                                                                                                                                                                                                                                                                                                | Matches the spec scenario: failed symbols stay retry-eligible on the next run.                                                                                                                                                                                                            | Setting `Complete = true` with an error annotation would silently bury the failure.                                                                                                                                                                                                                                                                                       |
| `**OperationCanceledException` bypasses the symbol-scope catch.** The `catch` filters on `when (ex is not OperationCanceledException)` (or re-throws in the handler).                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Cancellation tokens must terminate the run promptly; swallowing them would break the CLI ctrl-C contract and the cancellation scenario in the parent spec.                                                                                                                                | Swallowing every exception — violates cancellation semantics.                                                                                                                                                                                                                                                                                                             |
| **Log level is `Warning`, not `Error`, for per-symbol failures.** Includes `symbol`, exception type name, and `ex.Message`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | A single symbol failure is recoverable and expected on the long tail; `Error` is reserved for whole-run failures.                                                                                                                                                                         | `Error` would pollute alerting pipelines.                                                                                                                                                                                                                                                                                                                                 |
| **No change to `SqlitePerSeriesCandleStore`.** It already uses `"{table}"` quoting; our predicate already forbids `"` and control characters, so the stored identifier is always safe.                                                                                                                                                                                                                                                                                                                                                                                                                                 | Smallest surface area. The storage rewrite lives in the follow-up change.                                                                                                                                                                                                                 | Switching storage now — scope creep.                                                                                                                                                                                                                                                                                                                                      |
| **Tests at two levels.** `SeriesTableNaming` unit tests assert: accepts `BTCUSDT`, `龙虾USDT`, `1000PEPEUSDT`, `4USDT`; rejects empty, `"a\"b"`, `"a\u0001b"`. `Usdm1dBackfillOrchestrator` tests use a fake exchange returning a mix of healthy + failing symbols and assert: no exception escapes, healthy symbols written, failing symbols' checkpoint entries carry `LastErrorMessage`, `Complete` not set on failed entries, cancellation still propagates.                                                                                                                                                         | Mirrors the two ADDED requirements in the spec delta.                                                                                                                                                                                                                                     | End-to-end integration test against real Binance — out of scope for a unit-level fix; the live integration test project already exists and will exercise the Unicode path organically on the next run.                                                                                                                                                                    |
| **Document the identity debt.** A short entry in `src/platform/TradingPlatform/docs/ADRs.md` notes that the surgical fix preserves the raw-symbol-as-identity shape and points to `marketdata-instrument-identity-and-candles-registry`.                                                                                                                                                                                                                                                                                                                                                                                        | Keeps reviewers and future maintainers from re-tightening the predicate without knowing the context.                                                                                                                                                                                      | Skip the ADR — the follow-up change loses its lineage.                                                                                                                                                                                                                                                                                                                    |


## Risks / Trade-offs


| Risk                                                                                                                                            | Mitigation                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Swallowing a bug that looks like a per-symbol failure but is actually global (misconfigured DB path, bad credentials, Binance outage).          | Log at `Warning` with symbol + exception type + message; if the *same* exception type fires on N consecutive symbols, operators see a clear pattern in logs. The long-term answer (fail-fast on global errors) belongs with the identity change, not here. |
| `ToUpperInvariant` on Unicode giving a surprising result for some exotic locale.                                                                | Relevant code points on Binance today are CJK, which have no culture-based uppercase mapping; `ToUpperInvariant` is identity on them. Tests pin the `BTCUSDT` (ASCII upper) and `龙虾USDT` (CJK identity) behaviors.                                         |
| A future Binance listing adds characters that *are* unsafe in quoted identifiers (unlikely, but a `"` in a symbol would poison `CREATE TABLE`). | The storage predicate rejects that symbol with a clear error; the orchestrator's per-symbol catch logs and skips it rather than aborting the run.                                                                                                          |
| Old checkpoint files produced by the current build fail to deserialize.                                                                         | Avoided by construction: new fields are nullable with `WhenWritingNull`; `schemaVersion` is unchanged. A regression test loads a pre-change checkpoint JSON fixture and confirms the new fields default to `null`.                                         |
| Someone adds a new domain rule later that re-introduces ASCII-only validation.                                                                  | ADR entry and the inline comment in `SeriesTableNaming` explicitly record the decision and its rationale, and point to the follow-up change.                                                                                                               |


## Migration Plan

- **Ship:** No new NuGet packages, no schema bump, no DB migration. The orchestrator on next run will (a) pick up any existing checkpoint unchanged, (b) retry any symbol that was stuck at the CJK crash point, and (c) back-fill the three CJK perps for the first time.
- **Rollback:** Revert the commit. Existing checkpoint files with the optional `LastErrorMessage` / `LastErrorAtUtc` fields remain loadable by the pre-change build (it will ignore unknown fields if `JsonSerializerOptions` uses the default behavior; a deliberate check of the loader against a post-change file is included in tasks).
- **Follows up:** Once `marketdata-instrument-identity-and-candles-registry` ships, `SeriesTableNaming`, the storage-boundary predicate, and the string-keyed checkpoint all retire together. The per-symbol `try/catch` carries over to the new orchestrator.

## Open Questions

- None. The identity/storage redesign is deliberately deferred to `marketdata-instrument-identity-and-candles-registry` and is not gated by any decision in this change.
